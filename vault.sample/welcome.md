# 欢迎使用 Local KB Workbench 👋

这是一个 **local-first** 的个人知识库与工作台：所有内容都是你机器上的纯 Markdown 文件，完全离线、数据自持。

## 试试这些

- **知识库**：左侧目录树浏览 / 新建 / 编辑，右侧实时预览
- **检索**：顶部搜索框输入关键词（支持中文子串），命中会高亮
- **任务**：看板拖拽流转 待办 / 进行中 / 已完成
- **报表**：根据文件变更自动生成日报 / 周报

> 本文件只是示例。复制 `vault.sample` 到 `vault` 后，你可以随意改写或删除它。
